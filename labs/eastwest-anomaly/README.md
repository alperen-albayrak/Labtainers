# eastwest-anomaly

**East-west traffic anomaly detection laboratory** (work in progress)

Term project for CENG519 Network Security (METU, 2026-27 Fall).
Author: Alperen Albayrak (2791036)

The lab will put an internal network under east-west (host-to-host) monitoring. Students will:

1. Observe benign internal traffic.
2. Launch a lateral-movement or abnormal internal behavior scenario.
3. Build or tune an anomaly detector on internal traffic.
4. Apply a defense.
5. Verify the results through automated assessment.

Status: Milestone 1 (topic selection). Lab containers and configuration will be added in Milestone 2.
